# importador_gnss

GNSS_Pos2QGIS

Importa, filtra e projeta arquivos .pos gerados por receptores GNSS/RTK

Desenvolvido para otimizar rotinas de licenciamento ambiental e topografia. O complemento automatiza a leitura de arquivos de saída (.pos) de receptores RTK, filtra discrepâncias baseadas no desvio padrão, reprojeta as coordenadas on-the-fly, suaviza traçados e entrega a geometria final com os atributos já calculados (hectares e metros) diretamente no QGIS.
